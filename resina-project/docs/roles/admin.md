# Admin Guide

This guide is for admin users working in the RESINA web portal.

## Quick Start

1. Open the Admin Portal and sign in with your admin email and password.
2. Use the left sidebar to move between Dashboard, Announcements, Analytics Report, and Admin Profile.
3. Review the Dashboard first if you need the latest sensor, weather, tide, and activity information.
4. Sign out when you finish your work session.

## Common Tasks

| Action | What to do |
| --- | --- |
| Click | Open Dashboard to review Current Sensor Status, Weather Update, Tide Monitor, and the Activity Log. |
| Review | Check the water-level card to verify the latest status, range, and update source. |
| Click | Open Announcements to create, edit, search, filter, and delete announcements. |
| Upload | Attach images to an announcement before publishing it to residents. |
| Open | View announcement comments to monitor feedback, reply if needed, or remove unsafe content. |
| Click | Open Analytics Report to filter history records and export PDF or XLSX reports. |
| Search | Use the report tools to find records by water level status or date range. |
| Click | Open Admin Profile to manage personnel accounts, add users, update roles, or remove users. |
| Submit | Save role or profile changes only after confirming the updated account details. |
| Click | Sign Out when the portal is no longer needed. |

## Troubleshooting

- If the portal sends you back to the login page, confirm that your account is assigned an allowed role.
- If you cannot save a personnel change, check whether the account is the last remaining admin.
- If reports do not export, reload the page and try again after confirming the browser allows downloads.
- If comments or announcements appear incomplete, verify your connection and refresh the page before retrying.

## Data Privacy & Ethics

- Admin pages can expose sensitive resident data, account data, comments, activity logs, and exportable reports. Handle all of it as confidential.
- Only access records you need for your job, and follow least-privilege access when changing user roles.
- Treat passwords, reset links, session tokens, and any encrypted or masked data as confidential. Never store them in unsecured notes or chat tools.
- Do not export, forward, or screenshot resident records unless the data is required for an approved administrative task.
- Keep role changes accurate and auditable. Avoid unnecessary role escalation and preserve at least one valid admin account.
